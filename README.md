# Сжатие графов

Программа на C++20 сжимает неориентированный граф из TSV в бинарный файл и
восстанавливает его обратно. Поддерживает петли; ID вершин — uint32, веса — uint8.

## Файлы проекта

| Файл или папка | Назначение |
|---|---|
| `results/` | Папка с результатами работы |
| `src/` | Папка с исходниками проекта |
| `Makefile` | Команды сборки и очистки |
| `README.md` | Описание репозитория |
| `*.tsv` | Входные графы |

## Сборка и запуск

Нужны компилятор с поддержкой C++20 (например, GCC) и `make`.
Команды выполняются из корня проекта:

```sh
make
mkdir -p results
./run -s -i small_example.tsv -o results/graph.bin
./run -d -i results/graph.bin -o results/restored.tsv
```

`-s` — сжатие, `-d` — восстановление, `-i` — входной файл, `-o` — выходной.
Путь результата задаётся через `-o`.

## Как устроено сжатие

Вершины получают компактные индексы, рёбра сортируются и хранятся один раз —
у меньшего конца. Программа сравнивает несколько кодеков для исходных ID,
длин списков и соседей, затем записывает самые компактные варианты.
Веса хранятся по одному байту на ребро.

Заголовок содержит выбранные кодеки, размеры секций, число
вершин и рёбер, контрольную сумму. Восстановление выполняется самой C++-программой
и не требует исходного TSV или вспомогательных файлов.

`make clean` удаляет собранную программу; входные данные и результаты сохраняются.
